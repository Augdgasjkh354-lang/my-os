# my-os

个人专属 AI 操作系统（阶段1）。纯前端静态部署，数据 100% 存在浏览器 IndexedDB。

## 项目定位

- 单页应用（无 npm、无构建）
- 所有外部 API 统一走 Cloudflare Worker 代理
- 隐私优先：不上传任何个人数据到项目服务器

## 首次使用

1. 打开设置页，先填写代理配置（Worker URL、Access Token）
2. 填写各数据源和 AI 模型 API Key
3. 可选：搜索并保存城市位置
4. 后续功能阶段会基于本地已保存配置运行

## 隐私说明

- 配置、任务、记忆、对话、报告等数据都仅保存在本地 IndexedDB
- 可用「导出全部数据」下载备份 JSON
- 可用「从备份恢复」覆盖导入本地数据
